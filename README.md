## 产品综述｜PHP 域名授权验证系统开源版，源码版权保护、域名 IP 在线鉴权中台

在 PHP 源码、商城系统、模板插件、UniAPP 多端程序商用交付场景中，版权防盗、域名绑定授权一直是开发者痛点。市面上很多授权系统要么加密闭源、收费高昂，要么功能单一，仅支持简单域名判断，极易被 hosts 伪造绕过。**PHP 域名授权验证系统开源版**，基于 PHP+MySQL 开发，全开源无核心代码加密，一套独立授权中台，为你的 ThinkPHP 商城、各类 PHP 程序、UniAPP 多端项目提供域名 / IP 在线验证、卡密授权、盗版追踪能力，是源码服务商、独立开发者低成本搭建自有版权验证平台的首选方案。

系统定位独立授权服务端，部署在你自己的服务器。你把一段简短的客户端验证代码嵌入到待保护的 PHP 程序（例如前面 ThinkPHP 商城 PC 端、UniAPP 后端接口），程序启动时自动请求授权服务器 API，校验当前域名、服务器 IP、授权有效期。校验通过正常运行；未授权、过期、域名不匹配则限制功能、弹出提示，实现源码版权管控。

开源版内置完整后台管理 + 自助前台。后台支持新增授权记录、绑定单域名、泛域名、IP 授权，设置永久授权、按年 / 按月到期时间；批量生成卡密，支持卡密自助兑换授权、更换绑定域名；内置盗版入库功能，当未授权域名访问你的程序时，系统自动捕获域名、IP、访问时间存入后台日志，方便追踪盗版站点。前台自适应 PC 与移动端，提供授权查询、卡密兑换、授权更换、程序包下载入口，客户可以自助激活授权，减少人工沟通成本。

系统支持多程序管理，可在后台添加多个项目，例如：ThinkPHP PC 商城项目、UniAPP 高级授权多端项目，每个项目分配独立 AppID，不同程序授权相互隔离，一套授权系统管理多款源码产品。支持代理模块，可创建代理账号，代理独立后台批量生成卡密、销售授权，适合源码分销业务。

开源版优势在于代码完全开放，无域名绑定锁死，支持深度二次开发。你可以修改 UI 界面、调整验证逻辑、扩展在线更新接口，对接自有订单系统自动发卡密。环境要求简单，PHP7.0~PHP8.1 + MySQL5.6 及以上，宝塔面板一键部署，访问`/install`在线安装。

对比商业闭源授权系统，开源版没有高昂授权年费，一次部署永久使用，数据完全存放在自己服务器，不用依赖第三方授权平台。适合源码开发者、软件服务商，用来保护 ThinkPHP 商城、CMS、插件、UniAPP 多端源码，实现域名授权管控、卡密售卖、盗版监控一站式管理。
